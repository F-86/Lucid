## 技术选型

| 项 | 决策 | 理由 |
|---|---|---|
| GUI 框架 | iced（不选 GPUI） | API 稳定、文档完善、学习价值 |
| 文本存储 | ropey（阶段三） | 循序渐进，O(log n) 性能 |
| Markdown 解析 | pulldown-cmark | 速度快、事件驱动、学习价值 |
| 错误处理 | thiserror | 工程化最佳实践 |

---

## 架构原则

| 原则 | 说明 |
|---|---|
| 模块独立 | editor/ 不依赖 iced，可单独测试 |
| 渐进式 | 4 阶段避免过度工程化 |
| 规则先行 | 代码写前规范已定 |
