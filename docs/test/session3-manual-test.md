# Session 3 手动测试指南

## 启动应用

```bash
cargo run
```

应用将启动一个 GUI 窗口，标题显示「未命名 — Lucid」

---

## 测试场景

### 1️⃣ 打开文件

**步骤**：
1. 点击工具栏上的「📁 打开」按钮
2. 系统文件对话框弹出（macOS Finder / Linux 文件管理器）
3. 选择一个 `.md` 或 `.txt` 文件
4. 点击「打开」

**预期结果**：
- ✅ 文件内容加载到左侧编辑框
- ✅ 右侧预览面板显示 Markdown 解析后的 HTML
- ✅ 标题栏变为「文件名 — Lucid」
- ✅ 工具栏显示「文件名」（无 * 号）
- ✅ 状态栏显示「✓ 已打开：文件名」

**测试文件建议**：创建 `/tmp/test.md`
```markdown
# 测试文档

这是一个**粗体**文本。

## 二级标题

- 列表项 1
- 列表项 2
```

---

### 2️⃣ 编辑文件

**步骤**：
1. 在编辑框中修改文本（如删除一行或添加一行）

**预期结果**：
- ✅ 标题栏变为「* 文件名 — Lucid」（出现 * 号）
- ✅ 工具栏显示「文件名 *」（出现 * 号）
- ✅ 右侧预览实时更新

**测试**：在编辑框中添加以下文本：
```
### 新增的标题
```

应该看到预览右侧立即显示对应的 HTML。

---

### 3️⃣ 保存已打开的文件

**步骤**：
1. 修改文件内容（使标题栏显示 *）
2. 点击「💾 保存」按钮

**预期结果**：
- ✅ 标题栏的 * 号消失，变回「文件名 — Lucid」
- ✅ 工具栏的文件名恢复为无 * 号
- ✅ 状态栏显示「✓ 已保存」
- ✅ 文件内容已实际写入磁盘

**验证方式**：
```bash
# 在另一个终端查看文件是否被修改
cat /tmp/test.md
```

---

### 4️⃣ 保存新文件（另存为）

**步骤**：
1. 点击「📁 打开」打开一个文件（或继续上面的编辑）
2. 清空所有内容或修改
3. 点击「💾 保存」

**预期结果**：
- ✅ 弹出「另存为」文件对话框
- ✅ 选择保存位置和文件名
- ✅ 点击「保存」后，标题栏更新为新文件名
- ✅ 状态栏显示「✓ 已保存」

**测试**：保存为 `/tmp/new_file.md`，然后验证：
```bash
cat /tmp/new_file.md
```

---

### 5️⃣ 取消对话框

**步骤**：
1. 点击「📁 打开」
2. 在弹出的对话框中点击「取消」或按 Esc

**预期结果**：
- ✅ 对话框关闭，应用状态不变
- ✅ 编辑框的内容和文件路径保持不变
- ✅ 状态栏无消息（或保留上一条消息）
- ✅ **关键**：无错误消息，应用正常工作

---

### 6️⃣ 修改指示符验证

**步骤**：
1. 打开一个文件
2. 编辑一个字符
3. 观察标题栏和工具栏

**预期结果**：
- 编辑立即出现 * 号
- 修改后应该看到：
  - 标题栏：「* 文件名 — Lucid」
  - 工具栏：「文件名 *」

**步骤继续**：
4. 点击保存

**预期结果**：
- * 号立即消失
- 标题栏：「文件名 — Lucid」
- 工具栏：「文件名」

## 边界情况测试

### ❌ 权限不足的文件

**测试**：
```bash
# 创建一个只读文件
echo "# 只读文件" > /tmp/readonly.md
chmod 444 /tmp/readonly.md

# 尝试编辑并保存
```

**预期结果**：
- ✅ 能正常打开
- ✅ 能正常编辑
- ✅ 点击保存时，状态栏显示「✗ 保存失败：权限不足」（或类似错误）
- ✅ **关键**：应用不 crash，能继续工作

**清理**：
```bash
rm /tmp/readonly.md
```

---

### ❌ 打开不存在的文件

**测试**：
1. 点击「📁 打开」
2. 输入一个不存在的文件路径（某些系统支持）
3. 尝试打开

**预期结果**：
- ✅ 显示「✗ 读取失败：No such file or directory」
- ✅ 编辑框内容保持不变
- ✅ 应用继续正常工作

## 性能测试

### 大文件编辑

**测试**：
```bash
# 生成一个 100KB 的 Markdown 文件
python3 << 'EOF'
with open('/tmp/large.md', 'w') as f:
    for i in range(1000):
        f.write(f"# 标题 {i}\n")
        f.write(f"这是第 {i} 段文本。\n\n")
EOF
```

**测试**：
1. 打开 `/tmp/large.md`
2. 编辑一些内容
3. 保存

**预期结果**：
- ✅ 打开时响应在 1-2 秒内
- ✅ 编辑时没有卡顿（可能需要短暂延迟显示预览）
- ✅ 保存时立即完成

## 故障排除

### 对话框不弹出

**可能原因**：
- rfd 在某些系统上需要特殊配置
- 终端权限不足

**解决方案**：
```bash
# 确保在 GUI 环境中运行
cargo run
```

### 文件保存失败

**检查**：
1. 文件是否可写
2. 磁盘空间是否充足
3. 查看状态栏错误信息

### 预览不更新

**这是正常的** - 当前版本没有防抖渲染。计划在 Session 5 改进。
