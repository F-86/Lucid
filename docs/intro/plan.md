# 四阶段规划 | plan.md

> 项目四个阶段的具体目标和验证方式
> 最后更新：2026-06-09

---

## 阶段一：最小可运行底座（1-2 周）

**学习重点**：所有权/借用、模式匹配、Elm 架构

**目标**：
- iced 框架启动
- 双栏布局（编辑 + 预览）
- 实时 Markdown 预览
- 文件打开/保存

**验证**：
```
cargo run 后：
1. 看到双栏界面
2. 输入 "# Hello" → 右侧显示标题
3. File → Open 能打开 .md 文件
4. File → Save 能保存修改
```

---

## 阶段二：权限与后台能力（3-4 周）

**学习重点**：生命周期、迭代器、异步/Future

**目标**：
- 撤销/重做（Ctrl+Z / Ctrl+Y）
- 异步文件 IO（不卡顿）
- 防抖渲染（输入 300ms 后解析）
- 主题切换（亮/暗）

**验证**：
- 编辑 1MB 文件，不卡顿
- Ctrl+Z 有效，可恢复
- 防抖工作（输入后延迟渲染）
- 主题切换生效

---

## 阶段三：业务核心功能（5-6 周）

**学习重点**：Trait、泛型、高级借用

**目标**：
- 引入 ropey（高效文本）
- 丰富 Markdown 渲染（标题、代码块、表格、列表）
- 工具栏快捷按钮
- 快捷键系统

**验证**：
- 多种元素正确渲染
- 代码块有语法高亮
- 工具栏按钮工作
- 快捷键有效

---

## 阶段四：工程化与稳定性（7-8 周）

**学习重点**：错误处理、测试、工程最佳实践

**目标**：
- 完善错误处理（thiserror）
- 单元测试 + 集成测试
- 配置持久化
- 代码文档（rustdoc）
- 应用打包

**验证**：
- `cargo test` 覆盖 ≥70%
- `cargo clippy` 无警告
- `cargo bundle` 成功
- 代码文档完整
