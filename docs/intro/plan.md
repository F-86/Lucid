## 阶段一：最小可运行底座（1-2 周）

**学习重点**：所有权/借用、模式匹配、Elm 架构

**目标**（Typora 风格）：
- ✅ iced 框架启动（已完成）
- ✅ 单框编辑 + 实时预览（已完成）
- ⏳ 预览与编辑框同步滚动（框架就绪）
- ⏳ 文件打开/保存（待实现）

**当前进度**：

✅ 已完成：
```
1. iced 0.14 框架启动 → iced::run(update, view)
2. 编辑框 + 预览面板双栏布局 → row![editor, preview]
3. 文本输入实时更新 → EditInput Message 处理
4. Buffer 缓冲区 → 基于 ropey，支持大文件
5. Message 系统 → EditInput, FileOpen, FileSave
6. 模块结构 → editor/, markdown/, ui/ 独立模块
7. 单元测试 → 3 个测试通过 (Buffer)
8. 编译检查 → fmt/clippy 通过，无严重错误
```

⏳ 待做：
```
1. [ ] Markdown 实时预览 (pulldown-cmark 解析)
2. [ ] 文件打开 (tokio 异步 I/O)
3. [ ] 文件保存 (std::fs 或 tokio::fs)
4. [ ] 快捷键绑定 (Ctrl+O/S)
5. [ ] 更新指示器 ("* 有修改")
```

**验证清单**：
```
cargo run 后：
☐ 1. 看到编辑框 + 预览面板
☑ 2. 输入文字 → 编辑框实时显示
☐ 3. 输入 "# Hello" → 预览显示为标题
☑ 4. 编辑和预览同页面（虽然预览内容还是文本）
☐ 5. File → Open 能打开 .md 文件
☐ 6. File → Save 能保存修改
```

## 阶段二：权限与后台能力（3-4 周）

**学习重点**：生命周期、迭代器、异步/Future

**目标**：
- 撤销/重做（Ctrl+Z / Ctrl+Y）
- 异步文件 IO（不卡顿）
- 防抖渲染（输入 300ms 后解析）
- 主题切换（亮/暗）

**工作分解**：
```
1. 实现 cursor.rs → line/col 定位，选区
2. 实现 history.rs → Action 栈，撤销/重做
3. 接入 tokio → 异步文件读写
4. Markdown 防抖 → 输入延迟 300ms 后触发解析
5. 主题系统 → Light/Dark 切换（iced::Theme）
```

**验证**：
- 编辑 1MB 文件，不卡顿
- Ctrl+Z 有效，可恢复
- 防抖工作（输入后延迟渲染）
- 主题切换生效

## 阶段三：业务核心功能（5-6 周）

**学习重点**：Trait、泛型、高级借用

**目标**：
- ✓ 引入 ropey（高效文本）- 已在 Buffer 中
- 丰富 Markdown 渲染（标题、代码块、表格、列表）
- 工具栏快捷按钮（加粗、斜体、代码、列表）
- 快捷键系统

**工作分解**：
```
1. Parser 实现 → 使用 pulldown-cmark 解析各类元素
2. Renderer 实现 → AST → iced Element 渲染
3. 工具栏增强 → 按钮对应快捷格式
4. 快捷键系统 → Ctrl+B/I/K 等快捷操作
5. 代码块语法高亮 → 可选集成 syntect
```

**验证**：
- 多种元素正确渲染
- 代码块有语法高亮
- 工具栏按钮工作
- 快捷键有效

## 阶段四：工程化与稳定性（7-8 周）

**学习重点**：错误处理、测试、工程最佳实践

**目标**：
- 完善错误处理（thiserror）
- 单元测试 + 集成测试
- 配置持久化（serde）
- 代码文档（rustdoc）
- 应用打包

**工作分解**：
```
1. 错误类型 → BufferError, ParseError, IOError 定义
2. 测试覆盖 → 目标 ≥70% 代码覆盖率
3. 配置系统 → 保存最近打开文件、主题偏好
4. Rustdoc → 所有 public API 有文档
5. 打包脚本 → cargo build --release, bundle 配置
```

**验证**：
- `cargo test` 覆盖 ≥70%
- `cargo clippy` 无警告
- `cargo bundle` 成功
- 代码文档完整
- 发布版本启动快速
